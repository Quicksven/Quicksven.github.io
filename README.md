# Quicksven.github.io

Interactive study guides for networking and security labs, hosted on GitHub Pages.

## Live pages

- **Landing page** — https://quicksven.github.io/
- **Cisco Packet Tracer Config Guide** — https://quicksven.github.io/cisco-packet-tracer.html
- **Pentest Lab Checklist** — https://quicksven.github.io/security-pentest-checklist.html

## Pages in this repo

| File | What it is |
| --- | --- |
| [`index.html`](index.html) | Landing page linking to the guides |
| [`cisco-packet-tracer.html`](cisco-packet-tracer.html) | Cisco IOS configuration guide — commands fill in your device values, built-in subnet calculator, VLANs, routing, ACLs, SSH and more |
| [`security-pentest-checklist.html`](security-pentest-checklist.html) | Guided pentest lab checklist — recon, enumeration, exploitation, privilege escalation, Active Directory and pivoting, with each command explained |

Each page is a single self-contained HTML file (no dependencies) and saves your progress in the browser. The guides are for authorised lab environments only.
