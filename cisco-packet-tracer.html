IOS command modes — how to move around the CLI

Every command below runs in one of these modes. If IOS rejects a command, you are almost always in the wrong mode. Type exit to go back one level, or end (or Ctrl+Z) to jump straight to privileged mode.

Switch>
User EXEC — just arrived. Look only.
enable
Switch#
Privileged EXEC — show commands, save, debug.
configure terminal
Switch(config)#
Global config — device-wide settings.
interface g0/0
Switch(config-if)#
Interface config — one port or interface.
exit / end
